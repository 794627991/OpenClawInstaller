# 🦞 OpenClaw 一键安装器 — 虚拟机验证清单

> 用途：在干净虚拟机（VM）中验证打包产物 `dist\OpenClaw一键安装器.exe`，
> 完全不碰开发机。推荐 VMware Workstation 或 Hyper-V。

## 一、虚拟机准备

- [ ] 新建 VM，装 **干净 Win11**（专业版/企业版均可，需 64 位）
- [ ] 内存 ≥ 4GB，磁盘 ≥ 40GB
- [ ] **不要装** Node.js / OpenClaw / 任何 npm 全局包（模拟"小白全新电脑"）
- [ ] 把 `dist\OpenClaw一键安装器.exe`（17.4MB）拷进 VM 桌面

## 二、启动与提权

- [ ] 双击 exe → 应弹 **UAC 提权**（uac_admin 生效）→ 点「是」
- [ ] 主窗口「OpenClaw 工作台」正常打开，左上角龙虾图标
- [ ] 窗口标题栏、玻璃拟态 UI 正常（默认龙虾粉主题）
- [ ] 右下角 🎨 可打开主题面板（11 配色 × 11 风格）

## 三、未安装态（全新环境核心验证）

- [ ] 首页显示「未安装」引导 → 点「开始检测环境」
- [ ] 检测结果：**网络 ✓ / Node.js ❌ / npm ❌ / OpenClaw ❌**（应为未安装，VM 无环境）
- [ ] 进入「安装位置」页 → 默认 D:\openclaw（VM 需有 D 盘或无则回退 C）
- [ ] 演练模式（如已设 OPENCLAW_DRY_RUN=1）：安装链路显示「跳过执行」不污染
- [ ] **真实安装**（不设演练变量）：自动下载安装 Node.js + npm -g openclaw
- [ ] 安装完成 → 自动进配置页（API Key 强制，不填无法下一步）
- [ ] 选服务商 + 填 Key → 5 步配置（onboard/gateway/skills）
- [ ] 完成页 / 回首页 → 状态卡显示 OpenClaw 版本 / Gateway 运行 / 模型已配

## 四、已安装态（启动器功能）

- [ ] 首页显示「已安装」→ 状态卡 3 行（版本/Gateway/模型）
- [ ] 「马上开始使用」→ 仪表盘窗口秒开、**自动认证**（不进登录页）
- [ ] 仪表盘：系统原生标题栏（最大/最小化/关闭）、底部完整、菜单键不被遮挡
- [ ] 仪表盘关闭后点「马上开始使用」→ 复用窗口（非重建）
- [ ] 「修复 Gateway」→ 真实 ping 探测 → 正常提示无需修复
- [ ] 「更换 AI 模型」→ 下拉显示已配置模型 → 选择自动切换
- [ ] 「＋ 管理模型」→ 添加/移除模型真实生效
- [ ] 首页状态 15s 自动轮询（网关变化反映到状态卡）

## 五、演练模式（可选交叉验证）

- [ ] 设置环境变量 OPENCLAW_DRY_RUN=1 再启动 → 底部提示条「仅安装动作不执行」
- [ ] 演练模式下：模型切换/增删/Gateway 修复**真实执行**（仅安装动作跳过）
- [ ] 演练模式不写注册表 PATH、不改 npm 全局配置

## 六、回归与异常

- [ ] 全程无崩溃、无资源缺失、无黑屏窗口
- [ ] 日志窗口滚动流畅；错误信息均为中文可读
- [ ] 关闭所有窗口 → 进程全部退出（无残留）
- [ ] 检查：任务管理器无孤儿进程；%LOCALAPPDATA%\OpenClaw 若生成日志无异常

## 七、杀软/依赖

- [ ] VM 自带 Defender 是否报毒/拦截（记录结果，评估误报策略）
- [ ] 如 VM 无 WebView2（Win11 默认有）：记录是否正常 / 需否引导安装
- [ ] exe 启动耗时（首启 vs 二次启动）
